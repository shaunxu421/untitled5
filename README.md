# Simple Ecommerce

一个基于 **Java Servlet + JSP + Maven** 的简易电商系统。

## 功能
- 用户登录/注册
- 商品浏览
- 购物车管理
- 订单处理

## 技术栈
- Java 8+
- Tomcat 8.5+
- Maven
- JSP + Servlet
- MySQL（可选）
